\# Food Delivery Time Dataset



\## Dataset Description



The dataset contains food delivery order information used to analyze

and predict delivery time.



\## Columns



| Column | Description | Type |

|---|---|---|

| Order\_ID | Unique order identifier | Integer |

| Distance\_km | Delivery distance in kilometers | Numeric |

| Weather | Weather condition | Categorical |

| Traffic\_Level | Traffic condition | Categorical |

| Time\_of\_Day | Time period of the order | Categorical |

| Vehicle\_Type | Vehicle used for delivery | Categorical |

| Preparation\_Time\_min | Food preparation time | Numeric |

| Courier\_Experience\_yrs | Courier experience in years | Numeric |

| Delivery\_Time\_min | Actual delivery time in minutes | Numeric |



\## Target Variable



`Delivery\_Time\_min`



The objective is to predict delivery time using distance,

weather, traffic, time of day, vehicle type, preparation time,

and courier experience.
